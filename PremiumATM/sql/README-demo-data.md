# Demo account setup

On first application launch, `Database.ensureDemoUser()` creates the demo user and account when the schema is present and the demo user is missing.

- Account: `1000000001`
- Demo PIN: `1234`
- Starting balance: ₹25,000.00
- Email: `demo@aurel.example`

This is explicitly sample data for local testing. Change or remove it before sharing a deployment. For transfer testing, create a second user/account using PBKDF2 hashes generated by `PinHasher`; do not insert a plaintext PIN.
